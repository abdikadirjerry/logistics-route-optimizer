# Meridian Freight Corridor Optimizer (`ts-logistics-route-optimizer`)

An interactive multi-stop freight route planner, nearest-neighbor sequence optimizer, and fleet emissions/cost estimator built with React, TypeScript, Vite, and Tailwind CSS featuring a deep maritime midnight glassmorphic interface.

## Features

- **Interactive SVG Corridor Radar:** Visualizes hub coordinates, leg distances in kilometers, and live waypoint ordering.
- **Nearest-Neighbor Route Optimization:** Automatically reorders stops from the origin terminal to minimize total transit distance and fuel burn.
- **Fleet & Payload Validation:** Compares Electric Van, Hybrid Box Truck, and Heavy Diesel Semi classes with overweight payload alerts and CO₂ footprint estimates.

## Setup & Running

```bash
cd ts-logistics-route-optimizer
npm install
npm run dev
```
